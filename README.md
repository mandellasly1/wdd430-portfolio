# WDD430 Portfolio

This is my portfolio project built with [Next.js](https://nextjs.org).  
It showcases my featured projects, including school work, open‑source contributions, and an e‑commerce application.

## 🚀 Live Deployment
[https://wdd430-portfolio-mandellasly1.vercel.app](https://wdd430-portfolio-mandellasly1.vercel.app)

## 🛠 Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Vercel (deployment)

## 📂 Project Overview
This portfolio highlights my projects and skills. It uses API routes for project data and dynamic rendering to display both school and open‑source work. The site is styled with Tailwind CSS and optimized for deployment on Vercel.

### 🔹 Featured Projects
- **Portfolio Website** — A Next.js app showcasing my projects and skills.
- **E‑Commerce Project** — A demo online store built with Next.js and Tailwind CSS.  
  Features include:
  - Product listing and detail pages
  - Shopping cart functionality
  - Checkout flow
  - Responsive design for mobile and desktop
